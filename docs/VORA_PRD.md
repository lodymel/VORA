# VORA Product Requirements Document (PRD) v1.0

> **Product Vision**
>
> **One sentence. One light. Your sky.**

------------------------------------------------------------------------

# 1. Product Overview

## Mission

VORA helps people pause for one honest moment every day. One written
sentence becomes one Light. Over time, Lights reveal emotional patterns
instead of overwhelming journals.

## Product Pillars

1.  Reflection
2.  Transformation
3.  Accumulation
4.  Self-discovery

------------------------------------------------------------------------

# 2. Brand Principles

Design keywords:

-   Calm
-   Editorial
-   Quiet Luxury
-   Dreamlike
-   Timeless
-   Soft
-   Premium
-   Human

Never feel:

-   Gamified
-   Cute
-   Busy
-   Decorative
-   Tech-heavy

# 6. Write Experience

Purpose: Transform one written sentence into one meaningful Light.

States:

Idle

Writing

Review

Creating Light

Complete

Rules:

-   Layout never shifts.
-   Components never move.
-   Only light, glow, opacity, blur and subtle scale animate.
-   Wait until speech finishes.
-   User confirms before Light creation.
-   User may edit AI reflection.

------------------------------------------------------------------------

# 7. AI Principles

Never judge.

Never force positivity.

Never rewrite personality.

Instead:

Distill emotional meaning.

Examples:

"I'm exhausted."

→ "Needing rest."

"I hate today."

→ "A difficult day."

Profanity should never appear in Sky.

Only emotional meaning remains.

------------------------------------------------------------------------

# 8. Sky

One Light = One Star.

Constellations emerge only after enough Lights.

Constellations represent recurring emotional themes.

Examples:

Hope

Growth

Rest

Wonder

Weekly Reflection explains WHY the constellation appeared.

Only light moves.

Glow

Breathing

Heavy particles

# 17. Success Criteria

After 30 seconds a first-time user should understand:

"I spoke."

↓

"My words became Light."

↓

"My Sky has begun."

------------------------------------------------------------------------

# 18. Design Principles Checklist

Every design decision must answer:

-   Does this strengthen the VORA brand?
-   Does it reduce visual noise?
-   Does it feel calmer?
-   Does it preserve layout stability?
-   Does it feel timeless?
-   Does it make emotion more visible?

If not, simplify it.
